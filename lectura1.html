Lectura 1: Algoritmia y Estructuras de Control

La lógica computacional comienza con la capacidad de dar instrucciones claras a la máquina. Un algoritmo es una secuencia finita de pasos lógicos diseñados para resolver un problema específico antes de ser traducidos a código de programación.

Condicionales (Toma de decisiones)

Las estructuras condicionales permiten que el programa tome decisiones basadas en evaluaciones lógicas (verdadero o falso).

if (edad >= 18) {
    System.out.println("Es mayor de edad");
} else {
    System.out.println("Es menor de edad");
}

Ciclos (Bucles)

Se utilizan para repetir instrucciones y optimizar la lógica. El ciclo for es ideal cuando sabemos cuántas veces queremos iterar, mientras que while se usa cuando dependemos de una condición dinámica.

Referencia: Joyanes Aguilar, L. (2008). Fundamentos de programación: Algoritmos, estructura de datos y objetos. McGraw-Hill.
