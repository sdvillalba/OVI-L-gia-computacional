1. Inicio

El siguiente sitio web con estructura de Objeto Virtual de Información (OVI) está enfocado en la Lógica Computacional y la Programación Orientada a Objetos (POO). Este recurso educativo está diseñado para facilitar la transición del pensamiento algorítmico secuencial a la estructuración de soluciones de software robustas modelando objetos del mundo real.

A lo largo de este sitio, exploraremos cómo las instrucciones de control matemático evolucionan hacia arquitecturas complejas. Entenderemos por qué los lenguajes fuertemente tipados requieren una lógica impecable para iterar datos, instanciar clases, proteger la información y garantizar la persistencia de los estados en archivos, habilidades esenciales para cualquier futuro ingeniero de software.

Objetivos del OVI:

  • Fundamentación Lógica: Comprender y aplicar algoritmos básicos, diagramas, y estructuras de control (condicionales y bucles) para dirigir el flujo de ejecución de un programa.
  • Gestión en Memoria: Dominar la lógica detrás del almacenamiento a través de arreglos unidimensionales y bidimensionales, aplicando métodos de iteración y búsqueda.
  • Modelado de Objetos: Interiorizar los cuatro pilares fundamentales de la POO (Abstracción, Encapsulamiento, Herencia y Polimorfismo) para crear código modular y reutilizable.
  • Arquitectura y Patrones: Implementar lógicas de diseño creacional (como el patrón Factory Method) y entender los procesos de persistencia de datos mediante la manipulación de archivos planos.
