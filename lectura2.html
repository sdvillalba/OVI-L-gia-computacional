Lectura 2: Arreglos y Gestión de Datos

En programación, a menudo necesitamos almacenar múltiples valores lógicamente agrupados. Aquí entran los arreglos (arrays) y las matrices.

Vectores (Arreglos Unidimensionales)

Un arreglo es una estructura de datos estática que almacena elementos del mismo tipo de manera contigua en la memoria.

    int[] calificaciones = {85, 90, 78, 92, 100};
    for(int i = 0; i < calificaciones.length; i++) {
    System.out.println("Nota " + i + ": " + calificaciones[i]);}

Lógica de Búsqueda y Ordenamiento

Una vez tenemos datos en un arreglo, la lógica computacional nos permite ordenarlos (ej. Método Burbuja) o buscar datos específicos (ej. Búsqueda Binaria o Secuencial).
