Actividades Interactivas

Pon a prueba tu lógica computacional resolviendo los siguientes ejercicios.

Actividad 1: Prueba de Escritorio (Dry Run)

Analiza el siguiente fragmento de código. ¿Cuál será el valor final de la variable contador al terminar la ejecución?

int contador = 0;
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 2; j++) {
        contador = contador + 1;
    }
}
