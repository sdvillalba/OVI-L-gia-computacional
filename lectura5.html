Lectura 5: Arquitectura, Archivos y Patrones de Diseño

A medida que la lógica de nuestro programa crece, necesitamos organizar el código. Aquí entra la arquitectura de software.

Patrón Factory Method

Es un patrón creacional que proporciona una interfaz para crear objetos en una superclase, pero permite a las subclases alterar el tipo de objetos que se crearán. Es muy útil, por ejemplo, en sistemas de ventas donde una fábrica de objetos decide si instanciar un "Postre", un "Helado" o un "Pastel".

Persistencia de Datos Lógica

Los objetos viven en la memoria RAM y mueren al cerrar el programa. Para persistir datos, utilizamos la lógica de manejo de archivos de texto (I/O). En Java, clases como FileWriter y BufferedReader permiten escribir objetos en archivos .txt para crear un historial persistente.

Referencia: Gamma, E., Helm, R., Johnson, R., & Vlissides, J. (1994). Design Patterns: Elements of Reusable Object-Oriented Software. Addison-Wesley.
